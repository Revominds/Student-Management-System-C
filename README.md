## Description:
A simple Student Management System written in C for Windows. This console-based application allows users to add, view, search, and delete student records. Data is stored in a text file (StudentDB.txt) in a readable, structured format, making it easy to manage and update student information. Features include input validation, a spinner animation for saving records, and a clean, menu-driven interface.

## Key Features:
- Add new student records with roll number, name, class, address, and percentage
- Display all student records in a neat tabular format
- Search for a student by roll number
- Delete a student record
- Input validation for numeric fields
- Text-based storage for easy portability and readability

## Technologies Used:
- Language: C
- Compiler: GCC / MinGW
- Platform: Windows

## Ideal For:
- Beginners learning file handling in C
- Students practicing console applications and menu-driven programs
- Simple record management projects
